What is this

agent-loop is a reference implementation of a streaming AI coding agent protocol. Model-agnostic core. Tool executors. NDJSON bridges. A mission orchestration layer when one prompt is not enough.

IN ONE BREATH:
Python package + Ink TUI + child-process bridge. You plug in a tool-calling model (or replay a fixed tool sequence) and get structured lifecycle events at every layer. 
pip install -e .
python3 -m pytest -q
cd tui && npm install && npm run build

Streaming lifecycle

Every tool call follows the same three beats. Adapters (TUI, Telegram, headless controllers) render from these — they do not guess.

EventMeaning
ToolCallStartedEventAbout to run tool X with args
ToolCallDeltaEventIncremental output (stdout, stderr, thinking)
ToolCallCompletedEventFinal result or error
 
from agent_loop import Agent
from agent_loop.tools import ShellExecutor, ReadExecutor

agent = Agent()
agent.register_tool(ShellExecutor())
agent.register_tool(ReadExecutor())

for event in agent.run("list the current directory"):
    print(event.event_type, event.tool_name)

LLM integration

LLMAgent drives a call-and-respond loop against a named provider. OpenAICompatibleChatClient is what CodingAgentHarness uses for OpenAI-shaped endpoints.

openrouterOPENROUTER_API_KEY

from agent_loop.llm import LLMAgent
from agent_loop.tools import ShellExecutor, ReadExecutor

agent = LLMAgent(
    provider="openrouter",
    model="deepseek/deepseek-v4-flash",
    executors=[ShellExecutor(), ReadExecutor()],
)
for event in agent.run("list python files"):
    print(event)

Coding harness

CodingAgentHarness wires local tools to a tool-calling model, keeps conversation history, injects workspace context (AGENTS.md, git status), and yields the same streaming events as Agent.run().

from agent_loop import CodingAgentHarness, OpenAICompatibleChatClient

model = OpenAICompatibleChatClient(
    model="deepseek-v4-flash",
    base_url="https://opencode.ai/zen/go/v1",
    api_key="your-key",
)
harness = CodingAgentHarness(model_client=model, working_directory="/path/to/repo")

runner = harness.run("inspect the repo and run tests")
while True:
    try:
        print(next(runner))
    except StopIteration as done:
        print("reply:", done.value)
        break

Master loop harness

When a single prompt is too small. MasterLoopHarness runs long-lived missions that expand into goals, agents, workflows, and tool loops. Every layer emits LoopLifecycleEvent snapshots.

master top orchestrator
mission objective + cycles (finite or perpetual)
goal repeatable goal iterations
agent spawns workflows per goal
workflow one unit of work (LLM or tool_sequence)
tool wraps each ToolCall* event

Python

from agent_loop import (
    CodingAgentHarness,
    MasterLoopHarness,
    MissionLoopSpec,
    GoalLoopSpec,
    AgentLoopSpec,
    WorkflowLoopSpec,
)
from agent_loop.tools import ShellExecutor

coding = CodingAgentHarness(executors=[ShellExecutor()])
master = MasterLoopHarness(coding)

mission = MissionLoopSpec(
    objective="Keep the repo healthy",
    max_cycles=2,
    goals=[
        GoalLoopSpec(
            name="verify",
            objective="Run a lightweight health check",
            agents=[
                AgentLoopSpec(
                    name="maintainer",
                    workflows=[
                        WorkflowLoopSpec(
                            name="tests",
                            tool_sequence=[
                                {"tool": "shell", "args": {"command": "pytest -q"}}
                            ],
                        )
                    ],
                )
            ],
        )
    ],
)

for event in master.run(mission):
    print(event)

Bridges (NDJSON)

Two stdin/stdout bridges speak JSON lines. Controllers spawn them as child processes.

Headless: scripts/run-as-child.py

no model OK mode: mission 
echo '{
  "mode": "mission",
  "task": "check cwd",
  "tool_sequence": [
    {"tool": "shell", "args": {"command": "pwd"}, "call_id": "call_pwd"}
  ]
}' | python3 scripts/run-as-child.py

Emits loop_event, tool_started, tool_delta, tool_completed, done with loop_snapshot.

TUI backend: tui/bridge.py

needs model for LLM missions 
{"type": "ready", "tools": [...], "loop_snapshot": {...}}
{"type": "mission", "text": "run shell: echo hello"}
{"type": "loop", "event": "loop.started", "node": {...}, "snapshot": {...}}
{"type": "started", "call_id": "...", "tool_name": "shell", "args": {...}}
{"type": "completed", "call_id": "...", "result": {...}}
{"type": "reply", "text": "..."}
{"type": "done"}

Ink TUI

React + Ink terminal UI. Spawns tui/bridge.py. Shows a LoopDashboard tree with mission metrics and active-path highlighting.

cd tui && npm install && npm start
  • /mission <task> — route through master loop
  • /shell <cmd> — deterministic shell (no model)
  • Plain prompt — model-driven harness turn (needs AGENT_LOOP_MODEL)

Env: AGENT_LOOP_MISSION_CYCLES (finite repeats), AGENT_LOOP_PERPETUAL=1 (keep going).

DeepSeek v4 Flash (Hermes route)

Verified E2E: deepseek-v4-flash via OpenCode Zen Go + mission bridge. Chat, tool-calling, and full master loop completion. 
export AGENT_LOOP_MODEL=deepseek-v4-flash
export AGENT_LOOP_BASE_URL=https://opencode.ai/zen/go/v1
export AGENT_LOOP_API_KEY="$OPENCODE_GO_API_KEY"

printf '%s\n%s\n' \
  '{"type":"mission","text":"run shell: echo mission-llm-ok"}' \
  '{"type":"exit"}' | python3 tui/bridge.py

Same model on OpenRouter: deepseek/deepseek-v4-flash with AGENT_LOOP_BASE_URL=https://openrouter.ai/api/v1 and OPENROUTER_API_KEY.

Do not paste API keys into chat or commit them. Use env vars or Hermes credential_pool.
